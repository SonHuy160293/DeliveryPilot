## Story
As a vendor PM, I want to create an internal Scrum project without an engagement, so that non-client work uses the same delivery workflow.

## Context and boundaries

## Acceptance criteria
### AC-001 — Internal project
**Given** I hold the create-project permission **When** I create a project without an engagement **Then** a Draft internal Scrum project is created with me as administrator.

### AC-002 — Not visible to others
**Given** an internal project I created **When** another workspace member lists projects **Then** they do not see it.
