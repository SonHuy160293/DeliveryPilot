# US-DP-004-008 — Revoke a guest or leave a project

**Provenance:** Drafted 2026-11-09 with `dp-feature-engineer` from the roadmap, requirements, workflow discovery and [ADR-001](../../../architecture/adr-001-delivery-module-placement.md). ## Story
As a project administrator, I want to revoke a guest's access or cancel a pending invitation, and as a guest I want to leave a project, so that client access ends when it should.

## Context and boundaries


## Acceptance criteria
### AC-001 — Revoke
**Given** a client guest with earlier recorded decisions **When** I revoke the guest **Then** they are denied on the next request and their earlier decisions keep their attribution.

### AC-002 — Cancel pending
**Given** a pending guest invitation **When** I cancel it **Then** it can no longer be accepted.

### AC-003 — PO assignment ends
**Given** the revoked guest was client PO **When** I view the project **Then** the project shows no assigned client PO.

### AC-004 — Leave
**Given** I am a guest **When** I leave the project **Then** I no longer see it.
