## Story
As a project administrator, I want to add workspace members with one or more project roles, so that the delivery team can work in the project.

## Context and boundaries
Fixed template roles, additive permissions.

## Acceptance criteria
### AC-001 — Add member
**Given** I administer project P and Bob is an active workspace member **When** I add Bob as Developer and QA **Then** Bob can see P with the combined permissions of both roles.

### AC-002 — Non-member
**Given** Carol is not a member of the owning workspace **When** I try to add Carol as participant **Then** the request is rejected; Carol can only be invited as a guest.

### AC-003 — Scoped role
**Given** Bob is PM in project P **When** Bob opens project Q where he does not participate **Then** he gets not found.
