## Behavior and invariants

- Recheck current actor/target roles under the organization mutation guard. Admin membership removal and Admin role reduction require Owner. Owner targets use protected Owner control even with other roles; delegated ordinary-removal actor needs removal capability and all target effective powers within theirs.
- Normal Owner removal/demotion or step-down keeps at least one active eligible Owner; count active account/membership/assignment, not sessions. Two competing reductions cannot both commit an ownerless state.
- Member removal changes durable status to removed and revokes all surviving organization grants; preserve membership ID, original join time and all audit facts. Owner demotion removes only Owner, keeps other roles or assigns built-in Member if none remain.
- Require reason nonblank <=1,000 for reductions/removal. Audit failure rolls back. Fresh post-commit decisions deny revoked rights; admitted reads/commit-time Identity recheck/jobs use U19, not JWT-to-expiry grants.
- Compromised/suspended accounts denied immediately; no eligible Owner blocks privileged changes and no auto-promotion. Ordinary reads remain independently authorized; recovery remains out of scope.

## API contract (only for API tasks)

**Planned bearer routes:** POST /api/v1/organizations/{organizationId}/members/{membershipId}/remove and /demote-owner. Closed body {expectedMembershipVersion,reason}; caller identity never supplied. Success 200 -> {membershipId,status,roles,version,changed}; no-op repeat removal only if current actor may inspect/perform the result, otherwise generic denial. Demotion never grants a client-selected replacement role.

400 invalid reason/version/unknown fields; 401 unauthenticated; 403 Organization.AccessDenied for missing scope/target authority; 404 only scoped permitted missing target; 409 Membership.Stale, OwnerContinuity or invalid transition without private role facts for unauthorized caller; 503 unavailable required facts. Required history/commit failure does not return success. Admin role revoke remains task 006’s guarded endpoint and shares this protected policy.
