## Behavior and invariants

- Recheck current actor/target roles under the organization mutation guard. Admin membership removal and Admin role reduction require Owner. Owner targets use protected Owner control even with other roles; delegated ordinary-removal actor needs removal capability and all target effective powers within theirs.
- Normal Owner removal/demotion or step-down keeps at least one active eligible Owner; count active account/membership/assignment, not sessions. Two competing reductions cannot both commit an ownerless state.
- Member removal changes durable status to removed and revokes all surviving organization grants; preserve membership ID, original join time and all audit facts. Owner demotion removes only Owner, keeps other roles or assigns built-in Member if none remain.
- Require reason nonblank <=1,000 for reductions/removal. Audit failure rolls back. Fresh post-commit decisions deny revoked rights; admitted reads/commit-time Identity recheck/jobs use U19, not JWT-to-expiry grants.
- Compromised/suspended accounts denied immediately; no eligible Owner blocks privileged changes and no auto-promotion. Ordinary reads remain independently authorized; recovery remains out of scope.

## API contract (only for API tasks)

**Implemented bearer routes:** POST /api/v1/organizations/{organizationId}/members/{membershipId}/remove and /demote-owner. Closed API-local body {expectedMembershipVersion,reason}; require a positive long version and a nonblank reason of at most 1,000 characters under the existing safe audit-reason policy. Reject unknown fields and malformed bodies, enforce the shared 16,384-byte body ceiling, and retain the existing envelope and no-store headers on success and failure. Caller identity is never supplied. Success 200 -> {membershipId,status,roles,version,changed}, with roles shaped as {id,code,name}; no-op repeat removal only if the current actor may inspect/perform the result, otherwise generic denial. Reauthorize before deciding no-change or stale intent; an authorized unchanged removal returns changed:false without a new revision or success audit, including a stale positive version. Self-removal does not authorize a subsequent replay. Demotion never grants a client-selected replacement role or treats an arbitrary non-Owner target as proof of a prior demotion.

400 invalid reason/version/unknown fields; 401 unauthenticated; 403 Organization.AccessDenied for missing scope/target authority; 404 Membership.NotFound only after workspace/action and target-read authorization; 409 Organization.MembershipStale for a stale differing intent, Organization.OwnerContinuityRequired for continuity, or Organization.MembershipInvalidTransition for a readable unsupported state; generic denial when state disclosure is unauthorized; 413 oversized body; 503 unavailable required facts; safe 500 for unexpected persistence failure. Required history/commit failure does not return success. Admin role revoke remains task 006’s guarded endpoint and shares this protected policy.
