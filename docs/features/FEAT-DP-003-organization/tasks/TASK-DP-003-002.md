## Behavior and invariants

- Use the core table definitions in [Identity dictionary](../../../architecture/modules/identity/data-dictionary.md); retain OrganizationId, scalar local User IDs, UUIDv7 identities, active/suspended/removed domain states and existing field lengths. No exclusive OwnerId or global workspace-name uniqueness.
- One durable Organization/User pair across all lifecycle states; stable membership/role assignment pair with GrantVersion increasing only for a genuine new grant period. Removed membership ends current grants; rejoin does not resurrect historical powers.
- Map Version as an application-managed concurrency token. Domain methods maintain UTC UpdatedAt and Version explicitly: these plain classes do not inherit automatic audit behavior. Preserve protected system/custom role origin, immutable scoped Code, name case-insensitive uniqueness and permission-set versioning.
- Use composite same-organization role/member references and restricted deletion; local FK existence is not current authorization. Owner continuity is enforced by task 004/handlers, not an unsupported cross-row SQL CHECK.
