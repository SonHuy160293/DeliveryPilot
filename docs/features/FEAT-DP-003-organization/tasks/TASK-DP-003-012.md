## Behavior and invariants

- Only current active Owner nominates an active same-workspace non-Owner member; no new nomination for already-Owner target and at most one pending per workspace/member. Duplicate pending conflicts; expired pending closes before fresh nomination.
- Nomination alone grants nothing. Seven-day deadline; acceptance requires same nominated subject, active membership/account and current active Owner sponsor. Any current Owner may cancel; nominee may decline. No membership-invitation proof or automatic resend lifetime restart.
- First valid committed terminal transition wins; accepted replay is only current authorized already-accepted outcome with no new grant. Close nomination and add protected Owner assignment/new grant period plus audit together.
- Existing Owners remain after acceptance. Transfer is a later explicit 011 step-down with required reason and continuity; Member fallback/retained roles are not part of the acceptance transaction.

## API contract (only for API tasks)

**Planned bearer routes:** POST /api/v1/organizations/{organizationId}/ownership-nominations {membershipId} -> 201 NominationSummary; GET same collection for Owners; GET /api/v1/me/ownership-nominations for only the caller’s eligible nominations. POST .../ownership-nominations/{nominationId}/accept or /decline {expectedVersion}; /cancel {expectedVersion,reason?} -> 200 terminal/current NominationSummary.

Summary: id,organizationId,membershipId,nominatedByUserId,status,createdAt,expiresAt,version,canAccept; scoped display names may reuse permitted member/own context, no email/proof. Only the nominated subject can accept/decline without gaining general member-list rights. List follows bounded keyset conventions.

400 invalid/unknown body; 401 unauthenticated; generic 403 wrong actor/workspace; 409 stale, pending duplicate, alreadyOwner, invalid sponsor/member or closed/expired transition. Same-subject terminal replay returns a currently permitted no-change result. Server obtains sponsor/time; no caller-selected Owner role or deadline.
