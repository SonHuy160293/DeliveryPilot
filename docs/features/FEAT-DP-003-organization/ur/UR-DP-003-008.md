# UR-DP-003-008 — Join or rejoin a workspace through an invitation

## Problem and context

An intended recipient needs a trustworthy way to join a workspace without sharing credentials. A returning member must not unknowingly regain old privileges.

## User need

As an **invited user**, I need to **accept a valid offer for my account and understand the organization roles being granted**, so that I can join or rejoin under explicit current authority.

## Business value and observable outcome

A matching signed-in recipient with valid proof can join under an unchanged authorized offer. Rejoin retains the relationship/history and grants only freshly authorized roles.

## Scope, constraints and exceptions

Valid single-use link plus matching current primary email supplies invitation-specific proof, without a fresh code or silent global verification. Seven-day lifetime, link rotation on resend and current sponsor authority apply. Restricted project guest admission is a different feature. BR-002/003/006/008; NFR-001/002/003/004/008.
