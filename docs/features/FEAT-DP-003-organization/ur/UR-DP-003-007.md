# UR-DP-003-007 — Maintain workspace ownership continuity

## Problem and context

Workspace responsibility must survive normal personnel changes. Granting ownership without the nominee’s agreement or removing the last active Owner creates governance risk.

## User need

As an **organization Owner**, I need to **nominate an existing member for additional ownership and obtain their acceptance**, so that responsibility can be shared explicitly while preserving continuity.

## Business value and observable outcome

Nomination alone does not grant ownership; accepted additional ownership leaves current Owners in place. Normal ownership reductions cannot orphan the workspace.

## Scope, constraints and exceptions

Multiple Owners, initial creator ownership and normal last-owner protection are selected. Additional ownership is distinct from transfer, demotion and emergency recovery. U15 selects seven-day in-app nominations, current sponsor/nominee eligibility, cancellation/decline and explicit acceptance-then-step-down transfer. Persistence is task design.
