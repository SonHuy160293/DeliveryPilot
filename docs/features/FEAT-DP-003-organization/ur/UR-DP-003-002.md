# UR-DP-003-002 — Invite and manage organization members

## Problem and context

People administering a workspace need scoped invitations and a permitted view of participation so they can onboard colleagues without sharing credentials or overgranting access.

## User need

As an **authorized workspace membership operator**, I need to **invite colleagues, follow invitation progress and inspect permitted membership details**, so that I can manage trustworthy enrollment.

## Business value and observable outcome

An invitation offers explicit roles to one recipient without granting access before acceptance. The operator can distinguish pending offers from actual members; U11–U13 establish list, invitation and management audiences with protected-target limits.

## Scope, constraints and exceptions

Workspace invitation powers are separate from project invitations. Multiple organization roles and constrained delegation are selected. Invitation lifetime is seven days; resend rotates proof and restarts the lifetime; acceptance checks current sponsor authority. AUTHZ-07/U11 selects Owners/Admins plus delegated member-list readers, and own-membership/role inspection. U12/U13/U18 select member fields, action defaults, original join time and active/default historical list behavior. BR-003/005/006/008; NFR-001/002/003/004/008.
