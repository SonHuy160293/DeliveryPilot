# UR-DP-003-001 — Create organization workspace

## Problem and context

A solo practitioner or agency founder needs a separate workspace ownership boundary after registration; registering a global account must not silently create a workspace.

## User need

As a **registered person**, I need to **create a workspace and become its initial Owner**, so that I can establish delivery work under an explicit ownership boundary.

## Business value and observable outcome

Creation establishes a named workspace with its initial Owner, or leaves no usable orphan workspace on failure. A person can separately create or join other workspaces.

## Scope, constraints and exceptions

Only a trimmed nonblank name up to 160 characters is required; duplicate names are allowed and no slug is required. Registration and project creation remain separate. BR-002/003/008; NFR-001/002/003/004. Additional ownership follows nomination and acceptance, not the initial-creator rule.
