# US-DP-015-004 — Withdraw something I shared

**Provenance:** Drafted 2026-11-10 with `dp-feature-engineer` from the roadmap, requirements, workflow discovery and [ADR-001](../../../architecture/adr-001-delivery-module-placement.md). Business choices marked **User-selected** were made by the user on 2026-11-10 (decision record in [feature.md](../feature.md)). `ready` records internal completeness review for task planning, not client approval; `approval_ref` stays null and nothing here is implemented.

## Story
As a vendor PM, I want to withdraw a shared item, so that the client no longer sees content that was shared by mistake or is out of date.

## Context and boundaries
Withdrawal ends access; it cannot recall what was already read.

## Acceptance criteria
### AC-001 — Withdraw
**Given** "assumptions" is shared **When** I withdraw it **Then** guests no longer see it and a direct request for it returns not found.

### AC-002 — History kept
**Given** I shared and then withdrew an item **When** I open the sharing history **Then** both actions show with actor and time.

### AC-003 — Retired stakeholder
**Given** a shared stakeholder entry **When** it is retired **Then** guests no longer see it.
