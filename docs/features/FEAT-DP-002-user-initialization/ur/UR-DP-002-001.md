# UR-DP-002-001 — Establish a platform user identity

## Problem and context
A new agency user or external collaborator needs a platform identity before joining delivery work. Anonymous self-registration using DisplayName, Email and Password is the confirmed initial flow.

## User need
As a prospective platform user, I need to establish my own platform identity and understand my next permitted step so that I can begin the onboarding journey without taking over another person's account.

## Business value and observable outcome
A valid applicant obtains an active platform identity and can sign in separately. Registration returns Created with userId; it neither verifies email nor automatically authenticates.

## Scope, constraints and exceptions
Email identifies a unique platform account across organizations. Registration creates no organization, membership, project or approver grant (BR-002/BR-004/BR-008). No verification, automatic login, abuse-limit subsystem or durable security-evidence work is included in this phase. Password confidentiality remains mandatory.

## Evidence and validation
The roadmap defines registration/login/logout.
