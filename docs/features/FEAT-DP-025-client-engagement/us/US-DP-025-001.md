# US-DP-025-001 — Record a new client engagement

**Provenance:** Drafted 2026-11-09 with `dp-feature-engineer` from the roadmap, requirements, workflow discovery and [ADR-001](../../../architecture/adr-001-delivery-module-placement.md). Business choices marked **User-selected** were made by the user in the joint feature review on 2026-11-09 (see the decision record in [feature.md](../feature.md)). `ready` records internal completeness review for task planning, not client approval; `approval_ref` stays null and nothing here is implemented.

## Story
As a vendor delivery manager, I want to record a client engagement for a signed fixed-price agreement, so that projects can start from an attributable client record.

## Context and boundaries
First step of VS-02 and LC01. Excludes projects (FEAT-DP-004) and client sharing (FEAT-DP-015).

## Acceptance criteria
### AC-001 — Create with required details
**Given** I hold `organization.engagements.create` in workspace A **When** I submit a client display name, agreement reference and signed date **Then** an Active engagement owned by workspace A is created with me as creator and the UTC creation time recorded.

### AC-002 — Missing permission
**Given** I am a member of workspace A without the create permission **When** I try to create an engagement **Then** the request is denied and no engagement exists.

### AC-003 — Tenant isolation
**Given** an engagement exists in workspace A **When** a read-all holder of workspace B lists engagements **Then** the workspace A engagement is not returned.

### AC-004 — Invalid input
**Given** I hold the create permission **When** I submit a blank client name or an http document link **Then** the request is rejected and nothing is created.

### AC-005 — Duplicate warning
**Given** an Active engagement with agreement reference FP-001 exists **When** I create another engagement with reference fp-001 **Then** it is created and I see a duplicate warning.

## Dependencies and testing notes
Requires Identity authority checks (TASK-DP-003-019) and entry codes (TASK-DP-003-020). PostgreSQL-backed tenant-isolation tests (D-07).
