# US-DP-025-008 — Link the engagement to the client's workspace with a code

**Provenance:** Drafted 2026-11-09 with `dp-feature-engineer` from the roadmap, requirements, workflow discovery and [ADR-001](../../../architecture/adr-001-delivery-module-placement.md). Business choices marked **User-selected** were made by the user in the joint feature review on 2026-11-09 (see the decision record in [feature.md](../feature.md)). `ready` records internal completeness review for task planning, not client approval; `approval_ref` stays null and nothing here is implemented.

## Story
As a vendor engagement manager, I want the client's Owner or Admin to confirm our link with a one-time code, so that both sides agree on who the client is without sharing access.

## Context and boundaries
Optional, informational link (D-09).

## Acceptance criteria
### AC-001 — Issue code
**Given** an Active engagement without a link **When** I issue a link code **Then** I see the code once and the engagement shows an outstanding code expiring in 7 days.

### AC-002 — Client confirms
**Given** a valid code **When** an Owner of client organization C enters it while acting in C and confirms **Then** the engagement is linked to C and nobody gains vendor project access.

### AC-003 — Member cannot confirm
**Given** a valid code **When** a plain Member of C enters it **Then** the confirmation is denied.

### AC-004 — Expired code
**Given** a code issued 8 days ago **When** an Admin of C enters it **Then** a generic failure is shown and no link is set.

### AC-005 — Remove
**Given** a confirmed link **When** an Admin of C or a vendor manager removes it **Then** the link is gone and history records who removed it.
### AC-006 — Remove on a Closed engagement
**Given** a confirmed link on a Closed engagement **When** an Admin of C or a vendor manager removes it **Then** the link is gone, the engagement stays Closed and history records who removed it.

## Dependencies and testing notes
Uses Identity's existing organization check; failed-attempt rate limit configured at task level.
